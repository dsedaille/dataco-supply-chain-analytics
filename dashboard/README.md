# Tableau Dashboard

This folder contains the Tableau dashboard screenshot for the DataCo Supply Chain Analytics project.

The dashboard summarizes key business metrics related to delivery performance, product profitability, and fulfillment operations. It is designed to provide a business-facing overview of the main project findings.

## Dashboard Focus

The dashboard answers the question:

Where are delivery, product, and operational risks affecting business performance?

## Key Metrics

- Total Orders
- Late Delivery Rate
- Total Sales
- Total Profit

## Main Views

- Late Delivery Rate by Shipping Mode
- Order Status Distribution
- Top 10 Product Categories by Sales
- Top 10 Product Categories by Profit
